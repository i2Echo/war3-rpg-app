## 补充说明：文档末尾规则

本文档末尾的说明部分已同步到系统中。

### 关于"不做炼化公式正则解析"的说明

**重要提示**：以下内容仅作为**进一步说明**，用于消除歧义。解析引擎默认不对说明区做正则化解析，**仅对明确规则型条件做结构化处理**（见下方例外条款）。

#### 说明部分概览

原始文档末尾包含的说明：

1. **稀缺度**：S ≫ A > B ≫ C=D=E=F
2. **优先级**：升级 > 平级 > 降级，然后是稀缺度，最后是成功率
3. **公式解释示例**：多品质选择、随机产物处理等
4. **高频物品列表**：梵天纹章等10件常用装备
5. **特殊后缀说明**：
   - (唯一)：全图任务唯一装备  
   - (卷轴合成)：仅能通过卷轴合成获得
   - (一次)：只能炼化一次

#### 解析引擎的处理原则

✓ **解析引擎会处理的内容**：
- 明确的数字成功率
- 特殊装备标记（唯一、卷轴合成、一次）
- 装备品质和属性
- 按内置规则计算炼化结果优先级
- 公式材料槽位中的排除条件：`非XXX` / `不包括XXX`（用于候选项过滤）
- 具体材料100%公式与泛化公式冲突时的候选排除（仅在冲突公式上下文生效）

✗ **解析引擎不处理的内容**：
- 括号内的普通说明文字（不含 `非` / `不包括` 的说明）
- 条件性文字描述（"或者"、"除了"等）
- 历史备注或特殊情况说明

### 特殊装备标记的实现

已在 `src/utils/recipeEngine.ts` 中实现：

1. **解析**：提取装备名称中的特殊后缀 `(唯一|卷轴合成|一次)`
2. **存储**：将后缀转换为 `special` 属性（unique/scroll/once）
3. **显示**：在UI右下标显示标记 `品质属性₍标记₎`

示例：
- `焚寂(唯一)` → 显示为 `A力₍唯一₎`
- `魔导师护胸改(卷轴合成)` → 显示为 `S智₍卷轴₎`
- `蓬莱仙珠(一次)` → 显示为 `S敏₍一次₎`

### 同步脚本的更新说明

`scripts/sync_formulas.py` 在同步数据时：

1. **读取**：`docs/西方世界的劫难3炼化公式.md`
2. **处理**：
   - 去除Markdown格式符号（##、-、>、** 等）
   - 保留特殊装备标记（唯一、卷轴合成、一次）
3. **输出**：
   - `src/data/formulas.txt` - 纯文本格式
   - `src/data/formulas.ts` - TypeScript模块

### 关键变更

#### 2026-03-06

1. **特殊装备属性标记规则**
   - 后缀不是名称的一部分，而是装备属性
   - 存储为纯净名称 + special属性字段
   - UI显示用右下标标注
   - 特殊装备不作为随机公式产物

2. **数据同步流程**
   - 从Markdown源文件自动提取特殊标记
   - 过滤Markdown格式符号但保留特殊标记
   - 生成规范化的txt和ts文件

3. **UI显示增强**
   - 装备右下标显示特殊标记
   - Modal标题支持显示卷轴合成标记
   - 查询结果中完整显示所有标记

#### 2026-03-19

1. **具体100%公式覆盖泛化候选**
   - 若存在具体材料且成功率为100%的公式，则在对应泛化公式的候选项中排除该具体材料
   - 仅在冲突公式上下文生效，不影响其他公式
   - 示例：
     - `千幕之夜+银河幻星鞋=真千幕之夜，100%`
     - 在 `千幕之夜+S敏捷=奥姆幽刃，100%` 中查看 `S敏捷` 候选时，排除 `银河幻星鞋`

2. **槽位排除条件（非/不包括）生效**
   - 解析并执行材料槽位中的 `非XXX` / `不包括XXX` 规则
   - 示例：
     - `S战武（非千幕之夜）+S敏捷=千幕之夜，100%`
     - 查看该公式中 `S战武` 候选时，排除 `千幕之夜`
